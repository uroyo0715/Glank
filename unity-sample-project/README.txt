Glank サンプルプロジェクト

■ 起動手順
1. このzipを解凍する
2. Unity 6000.4.9f1（このプロジェクトが作られたバージョン）を、お持ちでなければ
   Unity Hub経由でインストールする
3. Unity Hubの「開く」で、このフォルダ（unity-sample-project）を選択する
4. プロジェクトが開いたら、Assets/Scenes/SampleScene.unity をダブルクリックして
   シーンを開く
5. 再生ボタン（▶）でプレイモードに入る

■ Glankでバグ報告を試すには
Assets/Glank/GlankSettings.asset の apiKey は空にしてあります。
実際にバグ報告機能（ホットキーでの動画・入力ログ送信）を試すには、
Glankダッシュボードの自分のプロジェクトから発行したAPIキーをここに設定してください
（プロジェクトのバグ一覧ページ →「SDK接続情報」で確認できます）。
